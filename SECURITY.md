# Security policy

## Report a vulnerability privately

Use [GitHub's private vulnerability reporting](https://github.com/valentindimitrov/ntfy-desk/security/advisories/new).
Do not report vulnerabilities in public issues.

Include the affected version or commit, the browser and operating system, the steps to reproduce, and the
security impact you expect. Leave out real access tokens, topic names and message content; use a test
server and invented data to demonstrate a problem.

The maintainer will investigate and coordinate a fix and its disclosure with the reporter. This is an
independently maintained project: there is no guaranteed response time and no bounty.

## Supported versions

Security fixes go into `main` and the next release. Older releases don't receive separate fixes; use the
latest release, or a build of `main`, when verifying a report.

The website's [`security.txt`](https://ntfy-desk.minddevops.eu/.well-known/security.txt) points here.
