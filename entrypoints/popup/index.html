Keyboard shortcuts

Shortcuts are set in the browser's extension shortcut settings. Ctrl + Enter (⌘ + Enter on a Mac) sends from the Send form.

Backup

The file holds your server addresses, topic names and preferences, which can be enough to read a topic on a server without access control. It never holds the token, the password or messages. Importing replaces these settings.
