Get started with ntfy Desk

Install the extension, point it at your ntfy server, and choose the topics to follow.

Install Connect a server Add topics Send and receive Shortcuts

1. Install the extension

ntfy Desk runs in Chrome, Edge, Vivaldi and other Chromium browsers, and in Firefox 142 or later.

To load a release build by hand:

  • Chromium browsers. Download and extract the -chrome.zip file. Open the browser's extensions page, turn on Developer mode, then choose Load unpacked and select the folder that contains manifest.json.
  • Firefox. A permanent installation needs a signed add-on, which is not available yet. The Firefox ZIP is for temporary testing: open about:debugging#/runtime/this-firefox, select Load Temporary Add-on and choose the ZIP. It lasts until Firefox restarts.

2. Connect a server

Open ntfy Desk from the toolbar and select the gear icon. The settings open on the Server tab while there is no server yet.

  1. Server URL. Enter https://ntfy.sh or the address of your own server. If you don't know ntfy yet, start with the ntfy documentation.
  2. Fallback URL (optional). Another address of the same server, such as its public address when the main one is on your home network.
  3. Access Token, or Username and password, if your server or topics need them. They are stored on this device only and used only with server addresses you approved on it.
  4. Choose Save server settings. The addresses and the credentials are saved together.
  5. If Allow access to this server appears, select it. The browser then asks you to confirm. ntfy Desk needs that access to send requests with your credentials.

Use an HTTPS server and a topic with access control for anything sensitive: anyone who can read a public topic receives what you send to it. The settings warn you when an http:// address would send your credentials unencrypted.

3. Add topics

On the Topics tab, type a topic name and press Enter. A name has up to 64 letters, digits, dashes or underscores. ntfy Desk receives from the topics your credentials can read; a topic you can only write to appears as send only.

The table under the names sets three things for each topic. Choose Apply to save them.

Message sync
Keep received messages is the default: what you delete is deleted in this browser only. Sync server deletions also follows deletions made on the server, and asks the server to delete what you delete here.
Desktop notifications
All, a minimum priority, or off. Messages below the level still appear in the inbox.
Send priority and tags
Last used by default. Choose a priority to give the topic its own starting priority and tags in the Send form.

4. Send and receive

Go back to the main view. The inbox is on the left and the Send form on the right, in the toolbar popup and in the extension's own tab (Open in a tab in the header).

  1. Start with a harmless test: pick a topic under Send to, type a message and choose Send.
  2. The message arrives in the inbox and, depending on the topic's rule, as a desktop notification.
  3. Select a topic on the left to see only its messages. The Send form follows it; choose All topics to pick another destination.
  4. Add a priority, tags or files, or open More options for a click URL, Markdown and delayed delivery.
  5. On any web page, right-click to send the page, selected text, an image or a link. The toolbar icon shows ✓, ✗, or ? when the delivery is uncertain.

Live messages come over a connection that stays open; missed ones are also fetched once a minute. If your server is behind a reverse proxy, turn off response buffering for ntfy (nginx: proxy_buffering off;), or live messages only arrive with the next fetch.

5. Shortcuts

Ctrl + Enter
Send, while the focus is in the Send form. Cmd + Enter on a Mac.
Open ntfy Desk
Alt + Shift + N is suggested, where the browser has it free.
Send this page to ntfy
Publishes the current page's URL and title to the topic last chosen in the Send form, or to the first topic. It has no key until you choose one.

The last two are set in the browser's own shortcut settings. Change shortcuts on the More tab of the settings opens them.
