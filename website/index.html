Your ntfy topics, one click away

ntfy Desk is a browser extension for ntfy: send notifications to your topics, and receive them as desktop notifications with a message list per topic.

Works with ntfy.sh and self-hosted servers, in Chromium browsers 116 or later and Firefox 142 or later.

THE INBOX

Every message, sorted by topic

Live messages arrive over ntfy's JSON stream. When the browser starts, ntfy Desk catches up on the messages still in the server's cache, within ntfy's replay limits and the inbox's per-topic limit.

  • Topic filters with unread counts, and the unread count on the toolbar icon.
  • Search across the messages you have received.
  • Markdown is rendered, links open in a new tab, and images hosted on your server are previewed.
  • Mark a message read or delete it, and its desktop notification is dismissed too.
  • A message published again with the same sequence ID replaces its earlier version.
  • Deletion sync per topic, if you turn it on: a deletion on the server removes the message here, and deleting it here asks the server to delete it too.
DESKTOP NOTIFICATIONS

Interrupted only when it matters

Each topic has its own rule: show every notification, set a minimum priority, or turn desktop notifications off. The inbox still lists the messages.

  • In Chromium browsers, high and urgent notifications ask to stay on screen until dismissed, unless you turn that off.
  • A catch-up with more than five notifications shows one summary instead of a burst.
  • A click opens the message's link, or highlights the message in the extension tab.
  • In Chromium browsers, a notification can show up to two buttons for view actions and attachments.
THE SEND FORM

Say it with a title, a priority and a file

The Send form sits next to the inbox, in the toolbar popup and in the wide extension tab, and follows the topic you are reading.

  • Title, message, priority and tags.
  • Attachments: up to 100 files, 20 MiB each and 50 MiB together, sent one by one or as one ZIP.
  • A click URL, opened when the notification is clicked.
  • Markdown formatting.
  • Delayed delivery: pick a duration, or type anything ntfy accepts, such as 45m or tomorrow 9am.
  • Send defaults per topic: a topic can start with its own priority and tags.
  • Ctrl + Enter sends (Cmd + Enter on a Mac).
FROM THE PAGE

Send what you are looking at

Right-click to send the page, selected text, an image or a link to ntfy.

  • The shortcut Send this page to ntfy publishes the current page's URL and title to the topic last chosen in the Send form. It has no key until you choose one.
  • The toolbar icon answers with ✓, ✗ or ?, so you know whether the message went out.
  • Fill in the current tab puts the page's title and URL into the Send form instead.
SETTINGS AND BACKUP

Set it up once, take it with you

Five tabs hold everything: Server, Topics, Messages, Appearance and More. A dot marks a tab that needs your attention.

  • Export the settings to a JSON file and import them in another browser or profile, without browser sync.
  • The file has no token, no password and no messages.
  • A fallback URL for the same server, used when the main address doesn't answer.
  • Keep 50, 100, 250 or 500 messages per topic.
APPEARANCE

Arrange it the way you read

The topic list sits beside the inbox or above it. With the topics above, the inbox and the Send form share the whole width.

  • Light, dark, or the theme of your system.
  • Drag the dividers between the topics, the inbox and the Send form, or freeze them.
  • Comfortable or compact rows, and message times as "5m ago" or the date and time.
  • The toolbar popup and the extension tab remember their pane widths separately.
PRIVATE BY DESIGN

Between your browser and your server

Read the privacy policy

Credentials stay on the device

Your token or password is stored in this browser only and goes only to server addresses you approved there, in the Authorization header, never in a URL.

No telemetry

No analytics, no advertising and no service run by the developer. ntfy Desk talks to the ntfy server you configure. This website loads nothing from other sites either.

The server is not trusted

Messages are checked before they are stored and shown as text, never as HTML. Links open only if they are http or https, and image previews load only from your server's attachment route.
